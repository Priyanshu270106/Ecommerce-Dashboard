# Ecommerce-Dashboard
1. Project Title
   Analyzing Sales Ecommmers
2. Description
   Built an interactive dashboard in Power BI to analyze online sales data, helping identify sales trends and improve decision-making.
3. Tech Stack
   • Power BI - Mian data visyalization platform tools and technologies:
   • Power Query - Data transformation and cleaning layer for reshaping and perparing the data .
   • DAX( Data Analysis Expressions) - Used for calculated measures , dynamic visuals and conditional logic.
   • Data modeling - Relationship eastablished among table (Details and Orders) to enable cross-filtering and aggregation
   • File Format - .pbix for development and .png for dashboard previews.
